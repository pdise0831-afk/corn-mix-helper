꺼짐

GitHub 비공개 gist를 앱이 자동으로 만들어 주고받아요. 한 번만 설정하면 어느 기기에서 켤 때 불러오고 바꾸면 자동 저장돼요. 토큰은 이 브라우저에만 있고 공유되지 않아요.

꺼짐
GitHub 토큰 만드는 법 (한 번만 하면 끝)
  1. github.com 로그인 (없으면 무료 가입)
  2. 프로필 → Settings → 왼쪽 맨 아래 Developer settings
  3. Personal access tokens → Tokens (classic) → Generate new token (classic)
  4. Note 아무 이름 · Expiration No expiration · Scope는 gist 하나만 체크
  5. Generate token → ghp_… 복사 → 위 칸에 붙여넣고 켜기
  6. 회사 PC·노트북에서도 같은 토큰을 한 번만 붙여넣으면 끝나요

토큰은 이 브라우저에만 저장돼요. 지우려면 GitHub에서 Revoke 하세요.

토큰 없이 잠깐 옮길 때: 아래 코드를 복사해 다른 기기에서 불러오세요. 백업 파일로 저장·복원할 수도 있어요.
